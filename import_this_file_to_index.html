Integration & component controls

Each mixer-type-N concept contains typeN-tanks and typeN-mixer. Individual tanks use typeN-bin-M and include their rims and interiors. Existing m1- through m4- component IDs address the support, blade, shaft, motor and gearbox; hydraulic types also expose the column and cylinder. Type 4 keeps the blade below the continuous support in SVG paint order. Vessel numbers run left to right, with Type 3's lower vessel numbered 2.

ScadaMixers.setState(2, 'running');
ScadaMixers.setComponentState(4, 'motor', 'fault');
ScadaMixers.setComponentState(4, 'motor', 'idle'); // clear component glow
ScadaMixers.setGlow(false);
ScadaMixers.getState(2);
ScadaMixers.exportSVG(4);

States: idle, running, warning, fault, offline. This is a display API; it does not issue equipment commands. setState changes only the selected concept and its glow: Running uses green, Warning amber, Fault red, Offline blue, and Idle clears its halo. Other concepts are unaffected. setComponentState adds a local component indication. Only the explicit Glow all switch changes every concept together; its preview uses the selected state color, or green for Idle. Switching it off removes all halos without resetting states. A mixed checkbox indicates that only some concepts glow. getState(type).glow reports that concept's current glow, including component indications. Listen for scada-state-change on the document. Exports include the current visual state and no JavaScript.

All eight assets live inside scada-mixers and share equipment-concept. The new machine roots are mighty-mill, grinding-dispersing-machine and spike-mill, each with a machine assembly and named physical component groups. Concept 8 uses mixer-type-8, type8-tanks, type8-mixer, and m8- component IDs. Its additional scraper-blade is 0.75 times the central blade diameter, with separately addressable scraper-motor, scraper-shaft and scraper-drive.
